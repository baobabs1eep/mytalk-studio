# MyTalk 项目补充说明

## 1. 项目名称与主张

**MyTalk：从 TED Talk 到 My Talk 的表达成长平台**

从 TED 与生活中的触动出发，帮助新航道雅思托福学习者调用真实经验，完成符合考试场景、也属于自己的英语表达。

## 2. 我们看见的问题

看完一场 TED，心里很亮，却说不出为什么；刷到一句话，明明想回应，最后还是退出了；电影散场后有很多感受，却只发了一个“好看”。这些时刻并不缺少想法，只缺少一个能慢慢把话说完的地方。

学生的表达困难通常来自三件事：

1. 感触停留在片段，缺少整理与展开的入口。
2. 害怕说不清、被误解，公共表达的心理门槛很高。
3. 一次展示结束后，个人经历与表达进步没有被持续记住。

## 3. 命题回应

TED 为青年提供了高质量的全球思想输入。MyTalk 以 TED 为重要入口，同时允许用户把书、电影、校园、家庭与网络讨论中的感触带进来。学生可以把这些内容存入同一个“足迹”板块，再带入雅思托福真题，完成词汇、语法、句式和口语/写作训练。

## 4. 产品闭环

### 4.1 足迹：留下还没说出口的话

用户记录一句感受、一个情绪、一个疑问或一条没有发出的回应。用户也可以在足迹页面观看精选 TED 视频、字幕或重点片段，再留下自己的反应。纸条可编辑、打标签、回看，也能收藏图书馆中他人的表达。生活记录和 TED 灵感共同进入足迹，成为后续真题表达的个人素材库。

### 4.2 表达工坊：从足迹到 My Talk

用户可选择表达目标：

- 自由表达
- 雅思口语
- 雅思写作
- 托福口语
- 托福写作

用户可以选取 1 至 3 条足迹带入。系统通过多轮问题帮助用户追问“我为什么会这样想”，再提供与个人内容相关的词汇、搭配、语法和句式练习，包括中译英、句式改写、连接词练习与限时输出。

核心关系是：**题目提供表达场景，足迹提供个人内容，TED 提供思想与语言输入，AI 帮助用户完成语言转换。** MyTalk 帮助学生准备的，不只是考试答案，还有那些真正属于自己的表达。

### 4.3 思想图书馆：让表达被温和地看见

用户将作品制作成封面后分享进入图书馆。阅读者可以表达认同、留下温和追问、收藏一条足迹，再把被触动的想法带回自己的表达工坊。这里像一座可阅读的观点图书馆，也让表达具有真实的人际反馈。

### 4.4 成长主页：让积累变得可见

个人主页记录足迹、成稿、分享、常出现主题和表达日历。它让用户知道自己关心什么、哪些观点重复出现、表达正在怎样变化；持续学习由此从外部任务变成可感知的个人积累。

## 5. 用户体验示例

一位大学生看完一场关于 AI 与创造力的 TED 演讲，想到课堂上“只奖励标准答案”的经历，却不知道如何展开。她在足迹中写下一句反驳，随后在表达工坊选择“把 TED 感受变成自己的话”，带入两条相关足迹。AI 依次追问她看到的具体场景、真正介意的部分、希望他人重新思考的问题。她最终形成一篇题为《我为什么仍然需要提出问题》的 My Talk，并分享至思想图书馆。一次表达完成后，它也成为她成长主页里“AI”“教育”主题的一部分。

## 6. 差异化

| 常见产品 | 核心动作 | MyTalk 的做法 |
| --- | --- | --- |
| TED 内容推荐 | 看更多内容 | 从 TED 观点进入个人表达 |
| TED 摘要工具 | 更快看懂内容 | 追问用户与内容的关系 |
| 口语陪练 | 训练发音、语法 | 从个人足迹出发，在真题场景中练表达 |
| 雅思托福刷题 | 完成题目与答案 | 题目提供表达场景，足迹提供个人内容 |
| AI 写作工具 | 直接产出标准文本 | 引用足迹、保留用户编辑权与表达过程 |
| 单次演讲课程 | 完成一次任务 | 用足迹、图书馆与成长主页形成持续循环 |

## 7. 对新航道 TED 的价值

- 让 TED 内容从观看资源进入学生的日常表达训练。
- 将英语学习、批判性思维、公共表达与自我认知放在同一条成长路径中。
- 通过作品分享与主题沉淀，提高学生持续使用和持续学习的意愿。
- 形成可展示的青年表达作品集，为课程、社团、演讲活动提供延展空间。

## 8. Demo 说明与原型边界

本项目已完成可交互 Web 原型，展示完整的“足迹 - 工坊 - 图书馆 - 成长”闭环。原型用于验证产品流程、交互和价值主张。

当前版本为前端演示原型，内容生成与反馈使用可控的本地演示逻辑。为避免误解，现阶段：

- 未接入真实的大语言模型、TED 内容接口、雅思托福真题服务、语音识别或语音评分服务。
- 页面中的追问、草稿、反馈和思想图书馆内容均为示例数据或本地演示逻辑。
- 未建立真实用户账号、线上数据库或真实社区内容；保存、编辑、收藏等状态仅在当前浏览器中演示。

正式版本将逐步接入大语言模型、TED 字幕/文本解析、语音识别与表达反馈能力，并建立账户、内容库与社区服务；同时配套内容审核、举报、隐私保护与未成年人保护机制。
